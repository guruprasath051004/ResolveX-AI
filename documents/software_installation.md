# Software Installation

## Overview
Procedures for installing approved software on company devices.

## Steps
1. Verify software is on the approved list.
2. Use `winget install <package>` or internal package manager.
3. Run installer with admin rights.
4. Verify installation via `where <executable>`.
5. Record in asset inventory.
