# Hardware Failures

## Overview
Common hardware failure symptoms and replacement procedures.

## Symptoms
- Device does not power on.
- Frequent BSOD or kernel panic.
- Unusual noises from hard drives.
- Overheating warnings.

## Steps
1. Verify power cable and outlet.
2. Run built‑in diagnostics (`mdsched` on Windows).
3. Check device manager for hardware errors.
4. If under warranty, open a ticket via Service Request.
5. Document the failure and replace hardware according to asset policy.
