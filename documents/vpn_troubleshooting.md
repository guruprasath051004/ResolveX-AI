# VPN Troubleshooting

## Overview
Guidelines for diagnosing VPN connectivity issues.

## Common Issues
- Unable to establish VPN connection.
- Frequent disconnects.
- Slow performance.

## Steps
1. Verify internet connectivity.
2. Check VPN client logs.
3. Ensure correct server address.
4. Confirm firewall allows UDP/443.
5. Reinstall client if needed.
